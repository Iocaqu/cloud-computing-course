# Laboratory Activity 2: Build the Cloud Infrastructure Blueprint (Variant 2: Compact)

## Mission Overview
Investigated a Linux server (KillerCoda) as a simulated CloudNova Technologies cloud engineer, documenting its infrastructure and comparing it to real cloud provider services.

## Objectives
- Explain cloud infrastructure components
- Investigate Linux hardware/software resources
- Differentiate compute, storage, networking, identity
- Interpret relationships between components
- Create professional Markdown documentation
- Build the GitHub Cloud Computing Portfolio

## Cloud Infrastructure Components
- **Compute:** CPU + RAM (`lscpu`, `nproc`, `free -h`)
- **Storage:** disk + mounted volumes (`df -h`, `mount`)
- **Networking:** hostname + IP (`hostname`, `ip addr`)
- **OS:** distro + kernel (`os-release`, `uname -r`)

## Tools Used
KillerCoda · Git/GitHub · Markdown · Draw.io (diagram)

## Linux Commands Executed
`cat /etc/os-release` · `uname -r` · `lscpu` · `nproc` · `free -h` · `df -h` · `df -hT` · `hostname` · `ip addr show`

## Skills Learned
- Linux system investigation from the CLI
- Mapping OS resources → cloud concepts
- Comparing AWS/Azure/GCP services
- Markdown technical documentation
- GitHub portfolio management
