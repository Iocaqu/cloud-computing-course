# Google Cloud Platform Research

**Overview:** GCP runs on the same infrastructure as Google Search/YouTube/Gmail. Youngest of the big three, but the leader in AI/ML and container orchestration — GCP created Kubernetes.

**Global Infrastructure:** 40+ regions, 130+ zones, 200+ network edge locations; fewer regions than AWS/Azure but backed by Google's private global fiber network.

**Console:** Google Cloud Console (web), plus the `gcloud` CLI and Cloud Shell (free browser terminal).

**Four Core Services:**
| Service | Category |
|---|---|
| Compute Engine | Compute |
| Cloud Storage | Storage |
| VPC (global-scoped) | Networking |
| Cloud IAM | Identity |

**Three Advantages:**
1. AI/ML leadership — TPUs, Vertex AI, BigQuery ML
2. Kubernetes/container expertise — GKE is the most mature managed Kubernetes offering
3. Data analytics strength — BigQuery serverless data warehouse

**Enterprise Use Cases:** AI/ML research and production, big data analytics, container-native/Kubernetes apps, organizations wanting a global-scoped network without per-region VPC peering
