# Mission Reflection

**1. Which cloud platform impressed you the most?**

Out of the three, AWS stood out the most. It wasn't just the raw number of services — over 200 — but how consistently useful that breadth turned out to be during the client scenarios. Whether the need was a scrappy startup on a tight budget or a global e-commerce company needing worldwide auto-scaling, AWS had a strong, purpose-built answer for both without needing to look elsewhere.

**2. What similarities exist among AWS, Azure, and GCP?**

Underneath different branding, all three providers cover the same core ground: VM-based compute, object storage, virtual networking, identity and access management, managed SQL databases, and managed Kubernetes — all billed on a pay-as-you-go model. Learning one provider's structure makes the other two much faster to pick up, since it's mostly new vocabulary for concepts that already transfer.

**3. How do business requirements influence cloud platform selection?**

This lab's four client scenarios showed there's no single "best" cloud platform — only the best fit for a given situation. A Microsoft-heavy university benefits far more from Azure's Active Directory integration than from AWS's size. An AI research lab needs GCP's TPUs more than a big catalog. The right answer always traces back to budget, existing systems, and the specific technical problem being solved.

**4. What did you learn from acting as a Cloud Solutions Consultant?**

The biggest shift was realizing the job isn't "which platform is objectively best" but "what does this client actually need, and which platform's strengths line up with that." It's a business-analysis skill layered on top of the technical knowledge, not a replacement for it.

**5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?**

The portfolio now has a complete multi-cloud research package — three provider deep-dives, comparison and service-matching tables, and a full client recommendation report with a decision matrix — real, demonstrable evidence of evaluating cloud platforms against actual business needs.
