AWS Research 

Overview: Launched in 2006, AWS was the first major public cloud provider and remains the market leader with 200+ services — the broadest catalog of any provider.

Global Infrastructure: ~30+ regions, 100+ Availability Zones, presence on every continent except Antarctica; most regions have 3+ AZs for fault tolerance.

Console: AWS Management Console (web), plus AWS CLI, SDKs, and CloudShell for programmatic/browser-based access.

Four Core Services:

Service	Category
EC2	Compute
S3	Storage
VPC	Networking
IAM	Identity

Three Advantages:

Largest service catalog — a mature solution already exists for almost any use case
Most mature ecosystem — largest community, most tooling, most certified engineers
Global scale — extensive region/AZ coverage for low-latency, high-availability apps

Enterprise Use Cases: large-scale web/e-commerce hosting, big data analytics (Redshift/Athena), organizations needing the widest range of specialized managed services, media streaming/CDN (CloudFront)
